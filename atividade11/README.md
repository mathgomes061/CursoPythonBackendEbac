Sistema de Gerenciamento de Pokémon

Descrição
    Programa em Python para gerenciar Pokémons, permitindo cadastrar, listar e remover Pokémons, atualizar níveis, registrar capturas e consultar o histórico de capturas.

Requisitos
    Python 3 instalado.

Como executar
    Abra um terminal na pasta do projeto.
    Execute:
    python gerenciamento_pokemon.py
    Se necessário, utilize python3 no lugar de python.

Funcionalidades
    1 - Adicionar Pokémon.
    2 - Listar Pokémon em ordem alfabética.
    3 - Remover Pokémon.
    4 - Atualizar nível.
    5 - Registrar capturas.
    6 - Exibir histórico de capturas.
    7 - Sair do programa.

Estruturas de dados
    Dicionário: armazena os Pokémon e seus atributos.
    Lista: armazena o histórico de capturas.
